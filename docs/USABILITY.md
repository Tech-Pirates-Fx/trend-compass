# Trend Compass — Usability Testing Protocol & Feedback Template

**Objective:** Validate that non-expert users (students, educators, community members) can successfully navigate Trend Compass, understand the 4 core detective answers, interpret statistical significance, and export data without prior training.  
**Related Task:** `docs/TASKS.md` Task H5 / T14.  
**Ethical Note:** In accordance with team rules, proposed usability protocols are documented here; actual student participant responses must be recorded by human evaluators without fabricated feedback.

---

## 1. Participant Profile & Target Cohort

- **Cohort Size:** 5 non-computer-science / non-climatology students or community members.
- **Criteria:** Basic computer literacy; diverse academic backgrounds (humanities, arts, business, biology); no prior experience with Mann-Kendall statistics.
- **Environment:** Web browser (Chrome / Firefox / Edge) on laptop or desktop screen.

---

## 2. Test Protocol & Guided Scenarios

Evaluator instructs the participant to think aloud while attempting four distinct tasks:

### Task 1: First Impressions & Mascot Navigation (2 minutes)
- **Prompt:** *"You have just arrived aboard the Starship Trend Compass. Find out what this application does and introduce yourself to the ship's navigator."*
- **Success Criteria:** 
  - Locates the mission tag and hero summary.
  - Interacts with or reviews dialogue from Navigator Orion at bottom-left.
  - Successfully dismisses or minimizes the navigator dialog if desired.

### Task 2: Charting a Region (3 minutes)
- **Prompt:** *"Navigate to the Chart Room and set up an investigation for the Sahel region in Africa (or any country of your choice) for temperature anomaly over the last 25 years."*
- **Success Criteria:**
  - Understands the 3 steps: What (variable), Where (region), When (dates).
  - Uses the 3D globe or country search to select the region.
  - Successfully clicks 'Run investigation'.

### Task 3: Interpreting the 4 Detective Answers (3 minutes)
- **Prompt:** *"Look at the results screen. Tell the evaluator: (1) What was measured? (2) Where? (3) How much did it change per decade? (4) Is the trend statistically significant?"*
- **Success Criteria:**
  - Immediately identifies the 4 corresponding metric cards.
  - Understands the distinction between the rate per decade (+0.241 °C/decade) and whether the trend is statistically significant.
  - Notes the confidence interval and plain-language summary.

### Task 4: Exporting Data & Checking Provenance (2 minutes)
- **Prompt:** *"Download the raw numbers as a CSV file and find the cryptographic SHA-256 receipt proving where this data came from."*
- **Success Criteria:**
  - Clicks 'Export CSV' and confirms file download.
  - Scrolls to the Provenance panel and points to the official NASA GISS source and SHA-256 hash.

## 3. Post-Test Evaluation Form (System Usability Scale)

Participants score each item on a 1 (Strongly Disagree) to 5 (Strongly Agree) scale:

1. I think that I would like to use Trend Compass frequently for exploring Earth data.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

## 4. Qualitative Interview Questions

1. *"Did the space-pirate expedition theme and Navigator Orion mascot help you feel welcomed, or did it feel distracting?"*
2. *"Was it clear what 'statistical significance' meant in the verdict badge?"*
3. *"What was the most confusing term or step you encountered?"*
4. *"If you could add or change one thing to make your investigation easier, what would it be?"*
