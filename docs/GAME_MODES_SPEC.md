## 1. Goal
An ed-tech research game: several MODES, each built on a different real NASA dataset, with its own mechanic twist, palette, background, HUD frame colour and SFX set. First Mate Piper (existing mascot, 6 expressions) walks the player through every mode and shares SOURCED facts. Presentation target: pixel-art adventure with a framed HUD, a portrait + dialogue box, and an illustrated Mode Select hub (the mood of a friend's project, with original art, layout and text). Reuse the M1 engine, domain reducer, tools and receipts. Never replace them.

## 2. Token budget rules (the owner's quota is limited)
- Do not re-read docs or files not named here. No new docs except a STATUS entry (8 lines max). Logs go to files.
- Build once per mode, run unit tests once per mode, at most 3 screenshots per mode. No exploratory testing, no re-verification of finished work.
- Commit and tag after each step (`voyage-m2a`, `m2b`, ...). Chat reply at most 12 lines.
- Three strikes: after 2 failed attempts at a step, write a `HUMAN HELP` block in STATUS and move on.

## 3. Mode contract (each mode is independent)
Folder `web/components/game/voyage/modes/<id>/` with `mode.ts` (manifest), `scenes/`, `facts.json`, optional `tools/`. Manifest fields: `id, title, tagline, palette, hudFrameColor, backgroundKey, cardKey, sfxSet, tools[], twist, datasetKeys[], caseIds[], mentorIntro[]`. A single `modes/registry.ts` lists modes; the hub reads only the registry. Adding a mode must not edit another mode's folder.

A mode SHIPS (visible in the hub) only when ALL are true: real data file present; provenance `verified:true`; at least one case generated by the Case Builder rules; its tools work; at least 3 sourced facts; art slots filled or placeholders in place. Otherwise it is hidden (use `?allmodes=1` to show it with a "DATA PENDING" label for the owner). No decorative locked cards.

## 5. Piper walkthroughs and facts
- Piper speaks at most 2 short lines, non-blocking, skippable, once per first use of a tool and once in each debrief. Per-mode intro in `mentorIntro`.
- Facts live in `facts.json`: `{id, text (<=140 chars, plain English), sourceUrl, sourceTitle, retrievedDate}`. Maximum 6 per mode. A fact is allowed ONLY if the agent opened its source page this run; if the fetch fails, omit the fact. About datasets, instruments and methods, not sweeping climate claims. Paraphrase; no long quotes.
- Seed facts (still confirm on the page): GISTEMP combines NOAA GHCN v4 station data with ERSST v5 ocean data; its gridded files use a regular 2 x 2 degree grid; NASA updates the GISTEMP tables about the 10th of each month. Source: https://data.giss.nasa.gov/gistemp/
- Each fact shown becomes a collectible entry in the Atlas ("Piper's Log").
- Research log (export JSON/CSV): every receipt, tool result, estimate versus truth, and claim. This is the ed-tech deliverable.

## 6. Presentation
- Pixel-art look: open-licence pixel font via next/font (verify the licence and credit it), `image-rendering: pixelated`, framed HUD per mode colour, portrait + dialogue box for Piper, illustrated hub cards.
- Art through an asset manifest with placeholder fallback. The owner generates/places files; the agent never blocks on art.
  - Slots: `web/public/voyage-art/card-<id>.png` (512x512) and `bg-<id>.png` (1280x720) for ids heat, rain, ocean, green, sky, tide, lab.
  - Style lock for every image: "16-bit pixel art, limited 32-colour palette, crisp hard edges, no anti-aliasing, no text, no logos, original design, [subject]". Subjects: heat = a space galleon on a glowing amber sea under a huge red sun; rain = night ocean, storm clouds, silver rain, lightning; ocean = deep teal abyss, small submarine, glowing currents; green = green canopy planet from orbit, golden light; sky = violet dusk layers, haze, a satellite; tide = pixel lighthouse above rising waves at dawn; lab = ship research lab, screens, chart table.
- Credits for every font, pack and AI image in `docs/DATA_AND_AI.md` and the Sources page.

## 7. Giovanni CSV ingestion (how extra modes get real data without logins in code)
